# VERBA LATINA — 라틴어 동사 변화 인터랙티브 학습 사이트

국제학교 라틴어 동사 변화 수업용 사이트입니다. (다인원격평생교육직업학원)

- **메인 페이지**: 24개 장을 7부로 정리, 장별 최고 점수와 진도 표시
- **장별 페이지** (`chapter.html?c=1` … `c=24`): 📖 학습(설명·자동 변화표·예문) / ✍️ 연습문제(선택·쓰기·변화형 쓰기·형태 분석, 「채점하기」로 점수·정답·해설 확인) / 🏆 결과
- **동사 변화 실험실** (`lab.html`): 모델 동사 5개, 핵심 동사 40개, 이태동사 7개, 불규칙 동사 9개의 전체 변화표와 10문항 랜덤 드릴
- **음성**: 모든 라틴어를 클릭하면 재생. 기기의 라틴어/이탈리아어(신경망) 음성을 골라 고전식 또는 교회식 발음 규칙으로 다듬어 읽어 줍니다. (Chrome·Edge 권장)
- **언어**: 한국어 / English 전환
- 변화형은 `js/engine.js`의 활용 엔진이 장음 부호까지 자동 생성합니다. 정답 입력 시 장음 부호는 생략해도 됩니다.

교재 「The Big Book of Latin Verbs」의 구성을 참고하되, 설명과 예문은 저작권 문제가 없도록 새로 쓰고 바꾼 학습 자료입니다.
